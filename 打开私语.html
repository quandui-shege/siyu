私语 · v1.0.0.1

私语使用指南

选一个身份，聊一段属于此刻的对话。

三步开始

  1. 点左下角“输入api-key”，填写自己的 DeepSeek API Key。
  2. 点首页身份卡片或左侧“新对话”，选择身份和场景。
  3. 正常模式直接聊天；特殊模式先准备背景，再开始聊天。

01 · 选择你的身份

我是女生：你是一个和他认识的女生。他的语气带暧昧、讨好和卑微，但仍在意并服从自己的女朋友。

我是女朋友：你是他的女朋友。他会更黏人、低姿态地哄你，情绪随着这段对话发展。

02 · 正常模式与特殊模式

正常模式：直接进入日常聊天，不需要设置背景，也不会默认发生分手或争执。

特殊模式：先进入独立背景页，助手主动问“现在是什么情况？”。回答后，它会整理摘要，并按需要补充追问，每次最多两个问题。不想指定的内容可以说“不指定”。你可以继续补充或修改摘要，点击“确认背景，开始聊天”后才进入正式对话。

身份与开场背景开始后固定。想换身份或重新设定场景，请新建对话。背景准备记录与正式聊天分别保存。

03 · 发送消息与重试

输入文字后按 Enter 或点击发送；Shift + Enter 换行。回复句数在1～4句之间随机变化，每句显示为一个气泡，可以是长句或短句。目前支持文字和 Unicode 表情。

等待回复时发送按钮会暂停。失败后点击“重试”继续发送上一条消息；失败不会写入虚构的回复。背景设置也可以重试。

04 · 管理多个对话

左侧列表可以切换聊天。每段聊天分别保存自己的背景、消息和记忆，不会共享其他对话的内容。

每段对话右边的“⋯”菜单可以重命名或删除该对话。删除需确认，并会移除这段聊天的背景和记忆；重要聊天请先导出备份。

05 · 记忆保存在什么地方

聊天自动保存在当前浏览器的本地存储。用同一浏览器、同一文件位置重新打开，可以继续已有对话。长对话会整理较早的内容，并结合最近 12 轮消息继续回应。

隐私模式、清理浏览器数据、移动文件位置或更换浏览器，可能使原有聊天不可见。程序文件夹不会自动写入聊天记录，换电脑也不会自动带走浏览器中的记忆。

06 · 导出与导入聊天

导出聊天：点击左下角按钮，勾选要备份的聊天，支持多选和全选。点击“导出所选聊天”后，浏览器会下载 JSON 备份，包含所选消息、背景和记忆，不包含 API 密钥。

导入聊天：点击按钮选择之前导出的 JSON 文件。导入会追加聊天，不覆盖当前内容；重复导入可能产生另一份对话副本。可在换电脑、换浏览器后用它恢复聊天。

07 · API Key 与连接

使用自己的 DeepSeek API Key，需要联网并有可用余额。填写后再次打开“输入api-key”会显示“已填写”，仍可输入另一份密钥并点击“更换密钥”。“已填写”仅表示已录入，不代表接口已经验证有效。

密钥只在当前页面内存中使用，不写入程序文件或聊天备份。刷新、关闭或重新打开页面后，需要重新填写。生成回复时，当前对话与风格参考直接发送到 DeepSeek 官方接口。

连接失败时先检查网络、密钥和余额；浏览器或网络环境也可能限制本地网页联网。

08 · 分享给别人

分享版需发送完整文件夹，保留“agent功能”“记忆功能”和入口 HTML 的目录结构。对方双击“打开私语.html”，填写自己的密钥即可使用。若你自行放入了聊天备份，分享前请移走；原有聊天可另行按需导出。

私语是 AI 表达风格模拟，包含创作设定，不代表现实中本人的想法或真实经历。
