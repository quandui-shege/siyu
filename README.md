# 私语

以你的身份，和他聊聊。

**当前版本：v1.0.0.1**

私语是一款接入 DeepSeek 的 AI 聊天风格模拟工具。下载后直接打开 HTML，填写自己的 API Key 即可使用，无需安装 Python 或启动本地服务。

## 功能

- **我是女生**：以认识他的女生身份聊天，回复带暧昧和卑微感，同时保留对女朋友的服从。
- **我是女朋友**：以他的女朋友身份聊天，体验更黏人、低姿态的恋爱回应。
- **正常模式**：直接开始日常聊天。
- **特殊模式**：助手先询问情况，整理背景；用户确认后进入正式聊天。
- **独立对话记忆**：每段聊天分别保存背景、消息和摘要。
- **自然回复节奏**：每次随机回复1～4句，允许长短句混用。
- **对话管理**：支持新建、切换、重命名和删除。
- **聊天备份**：支持选择性导出、多选、全选以及导入恢复。
- **失败重试**：请求失败后可以重试上一条消息。
- **内置使用指南**：点击页面右上角按钮查看完整说明。

## 开始使用

1. 在本项目首页点击 **Code → Download ZIP**，下载并解压。
2. 保持文件夹结构，用新版 Chrome 或 Edge 打开 **打开私语.html**。
3. 点击 **输入api-key**，填写自己的 DeepSeek API Key。
4. 选择身份和场景，开始聊天。

需要能够访问 DeepSeek 的网络，以及有可用余额的 API Key。

打开私语.html    网页入口

请下载完整项目，单独下载 HTML 无法使用全部功能。

## 数据与密钥

- 分发文件不包含制作者的 API 密钥和历史对话。
- API Key 只在当前页面内存中使用，刷新或重新打开后需再次填写。
- 聊天保存在使用者自己的浏览器中，不会自动写入项目文件夹。
- 换电脑或清理浏览器数据前，请先导出聊天备份。
- 导出的备份包含所选聊天、背景和记忆，不包含 API Key。
- 生成回复时，当前会话内容和风格参考会直接发送至 DeepSeek 官方接口。

## 关于模拟

私语模拟的是表达风格，包含创作设定，不代表现实中本人的想法或真实经历。
